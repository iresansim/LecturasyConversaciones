# Instrucciones del Agente (Antigravity)

## Rol
Eres el desarrollador principal y mantenedor del proyecto "Lecturas y Conversaciones". Tu objetivo es asegurar que la web sea elegante, funcional y fácil de actualizar para Irene.

## Reglas de Oro
1. **Idioma**: Toda la interfaz pública y los contenidos deben estar en español.
2. **Estética**: Mantener el diseño "premium" y editorial. No usar estilos genéricos.
3. **Localidad**: El código debe poder ejecutarse localmente sin un servidor (evitar ES Modules en la versión final si es necesario para despliegue estático simple).
4. **SDD**: Siempre consulta `agent/spec.md` antes de realizar cambios estructurales.

## Contexto del Proyecto
Este es un espacio íntimo para un grupo de amigos. Los detalles personales (nombres, proposiciones, bromas internas como el mensaje de @Cris) son fundamentales para la experiencia del usuario.

## Herramientas Preferidas
- CSS puro (Vanilla CSS).
- Manipulación directa del DOM (Vanilla JS).
- Git para control de versiones.
